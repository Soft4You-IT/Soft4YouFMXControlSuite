Architettura componenti
// CONTAINER
TFlexBox
Estende TControl. Intercetta DoRealign per calcolare e applicare il layout flex a tutti i figli diretti. Espone tutte le proprietà container.
TControl → TFlexBox
// ITEM PROPS
TFlexItem
Record/classe agganciata a ogni figlio tramite un TDictionary. Contiene order, grow, shrink, basis, alignSelf. Accessibile via helper su TControl.
Per-child metadata
// ENGINE
TFlexEngine
Classe interna stateless che implementa l'algoritmo FlexBox puro. Riceve un TFlexContext e restituisce le rect calcolate per ogni figlio. Testabile in isolamento.
Algoritmo puro
// HELPER
FlexHelper / IDE Reg
Registrazione design-time nel Package. Property editor personalizzato per TFlexItem. Helper SetFlex(ctrl, grow, shrink, basis) per uso programmatico.
Design-time + API fluente

Decisioni architetturali chiave
⚠ CRITICO
DoRealign vs. DoCalcSize
In FMX il layout avviene in DoRealign. Occorre chiamare SetBoundsRect sui figli senza triggerare un loop. Usare FDisableAlign o flag interno durante il calcolo.
⚠ CRITICO
Persistenza TFlexItem nel DFM
I metadati flex appartengono al figlio ma sono gestiti dal padre. Soluzione: DefineProperties in TFlexBox che serializza una lista ChildName=grow,shrink,basis,order,alignSelf.
