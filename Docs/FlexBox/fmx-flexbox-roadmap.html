Component architecture
// CONTAINER
TFlexBox
Extends TControl. Intercepts DoRealign to calculate and apply the flex layout to all the direct children. Exposes all the container properties.
TControl → TFlexBox
// ITEM PROPS
TFlexItem
Record/class attached to every child through a TDictionary. Holds order, grow, shrink, basis, alignSelf. Accessible through a helper on TControl.
Per-child metadata
// ENGINE
TFlexEngine
Internal stateless class that implements the pure FlexBox algorithm. Receives a TFlexContext and returns the calculated rects for every child. Testable in isolation.
Pure algorithm
// HELPER
FlexHelper / IDE Reg
Design-time registration in the package. Custom property editor for TFlexItem. SetFlex(ctrl, grow, shrink, basis) helper for programmatic use.
Design time + fluent API

Key architectural decisions
⚠ CRITICAL
DoRealign vs. DoCalcSize
In FMX the layout happens in DoRealign. SetBoundsRect must be called on the children without triggering a loop. Use FDisableAlign or an internal flag during the calculation.
⚠ CRITICAL
Persistence of TFlexItem in the DFM
The flex metadata belong to the child but are managed by the parent. Solution: DefineProperties in TFlexBox that serializes a list ChildName=grow,shrink,basis,order,alignSelf.
